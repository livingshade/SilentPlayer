# 产品设计

## 产品定位

这是一个只播放本地音乐的个人播放器，不做流媒体、不做社交、不做推荐流。体验上接近 Apple Music、Spotify、Doppler、Foobar2000 mobile 这类成熟播放器，但重点放在本地曲库的可靠管理和稳定听感。

核心承诺：

- 打开快，扫描清楚。
- 本地音乐文件不上传。
- 不同歌曲之间音量尽量一致。
- macOS 和 iPhone 使用同一个曲库规则、播放队列规则和 normalize 规则。
- 图形界面优先服务聆听，不因后端能力增加而变成管理控制台。
- 复杂、批量和可脚本化的管理工作由 CLI 完整承载。

## 产品面职责

macOS、iPhone 和 CLI 使用同一套 Rust application services，但面向不同任务：

| 产品面 | 首要用户任务 | 应提供的能力 |
| --- | --- | --- |
| macOS / iPhone | 找到音乐并开始播放 | 曲库浏览、搜索、最近歌单、播放队列、播放控制、播放中信息、系统媒体集成 |
| CLI | 建立、整理、检查和迁移曲库 | 完整导入导出、歌曲原地编辑、metadata/封面/歌词、歌单 CRUD、分析、审计、修复及脚本化输出 |
| Rust services | 保证所有 target 行为和数据一致 | 领域规则、持久化、播放状态、应用服务和稳定 FFI/CLI API |

这里的“共享”是行为和数据兼容，不是界面功能对等。CLI 导入或修改的歌曲、歌单和分析结果必须能被 Apple 端读取和播放；Apple 端不需要暴露创建、重命名、排序、批量编辑、迁移等完整管理流程。

新增功能遵循以下判断：

1. 共享产品行为先进入 Rust application service，并有测试覆盖。
2. 管理能力在 CLI 中提供完整、可发现、可脚本化的入口。
3. 只有高频、与当前聆听直接相关、适合图形交互的动作才进入 macOS 或 iPhone。
4. Rust/FFI API 与 SwiftUI 控件禁止机械地一一映射。

## Apple 端信息架构

Apple 端围绕播放流程组织，而不是围绕数据库实体组织。

- 曲库：歌曲、专辑、艺人和本地搜索。
- 最近歌单：快速打开并播放 CLI 已整理好的歌单。
- 播放中：封面、进度、播放顺序、队列和歌词。
- 设置：仅保留影响聆听体验的少量选项。

macOS 使用侧边栏承载曲库、历史和最近歌单；iPhone 使用紧凑的 tab/navigation。低频但仍有必要的播放相关动作可以进入分组清晰的 More 菜单。歌曲编辑、歌单管理、分析、审计、迁移和调试信息不进入常驻导航或工具栏。

## 主界面

### 曲库

曲库页需要支持：

- 按歌曲、专辑、艺人、文件夹切换。
- 标题、艺人和专辑搜索。
- 播放全部、播放下一首、加入队列。
- 打开最近歌单和播放历史。

格式过滤、缺失封面检查、批量分析和其他维护工作由 CLI 提供，不占据播放器主界面。

### 播放中

播放中页需要支持：

- 播放/暂停、上一首、下一首。
- 拖动进度条。
- 循环：关闭、单曲、列表。
- 随机播放。
- 进入队列编辑。
- 在需要时查看歌词和基础曲目信息。

播放页默认不展示 gain、数据库状态、分析状态或歌曲诊断。只有真正影响当前播放的错误需要直接呈现。

### 队列

队列是主流播放器体验里很重要的部分：

- 当前播放项固定高亮。
- 可拖拽排序。
- 可从当前位置后插播。
- 可清空队列。
- 支持“播放下一首”和“加入队尾”。

队列是当前聆听会话的一部分，因此 Apple 端应提供完整、直接的编辑体验；持久歌单的创建、重命名、封面、批量排序和删除则属于 CLI 管理职责。

## Normalize

Apple 端只需要使用易懂的聆听选项：

- 响度归一化：开/关。
- 模式：单曲、专辑、智能。

文案应避免技术门槛，用户看到的是：

- “让不同歌曲音量更一致”
- “保留专辑原本的音量关系”
- “防止过响歌曲失真”

目标 LUFS、峰值限制、预放大、批量分析、缓存检查和重新分析属于 CLI 高级能力。

## 本地文件模型

iPhone 上不能像桌面系统一样随便扫描整个文件系统，所以建议支持：

- 从 Files App 选择文件夹。
- 从 Files App 导入单首或多首歌曲。
- 保存安全书签，后续继续访问用户授权过的目录。
- 可选复制到 App 沙盒，便于离线和后台访问。

macOS 上建议支持：

- 选择音乐目录。
- 监听目录变化。
- 可选读取 `~/Music`。

## MVP 范围

第一版应包含：

- 本地目录导入。
- 曲库列表。
- 本地搜索。
- 播放/暂停/上一首/下一首。
- 播放队列。
- 最近歌单和最近播放。
- 内嵌封面读取和缓存。
- 单曲 normalize。
- iOS 锁屏控制和耳机控制。
- macOS 菜单栏基础控制。
- 完整的 CLI 曲库、歌曲原地编辑、独立导出、歌单、分析、审计和迁移命令。

暂不做：

- 云同步。
- 在线歌词。
- 在线元数据补全。
- 社交、推荐、账号体系。
- 在 macOS/iPhone 中复制 CLI 的完整管理界面。
